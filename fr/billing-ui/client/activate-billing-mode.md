---
title: "Activer le mode facturation"
description: "Laisse le joueur cliquer sur un joueur cible pour ouvrir le menu de facturation."
icon: "hand-pointer"
---

Déclencheur pour activer le mode facturation, le joueur devra alors cliquer sur le joueur cible et le menu de facturation s'ouvrira ensuite.

```lua Event
TriggerEvent("billing_ui:activateBillingMode")
```
