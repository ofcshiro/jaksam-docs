Quelques concepts utiles pour bien démarrer avec le script.

### Qu'est-ce qu'une mission ?

Une mission est un groupe d'étapes. Une fois toutes les étapes terminées, la mission est conclue.

### Qu'est-ce qu'une étape ?

Une étape est un groupe de tâches et d'actions.

### Qu'est-ce qu'une tâche ?

Les tâches sont des objectifs que les joueurs doivent accomplir pour progresser dans la mission. Quand toutes les tâches obligatoires d'une étape sont terminées, la mission passe à l'étape suivante.

Quelques exemples de tâches :

- **Aller aux coordonnées** : les joueurs doivent atteindre les coordonnées pour réussir cette tâche.
- **Livrer un véhicule** : les joueurs doivent livrer un véhicule à une zone que tu définis.

### Qu'est-ce qu'une action ?

Les actions sont ce que le script fait automatiquement pendant ta mission pour la rendre fluide et intéressante, par exemple :

- Faire apparaître des entités
- Donner des items
- Alerter la police

Il y a 2 types d'actions :

- **Actions de démarrage** : ce qui se passe dès qu'une nouvelle étape commence.
- **Actions de fin** : ce qui se passe dès qu'une étape se termine.

## Suggestion finale

Si tu veux voir comment fonctionne une mission complète, importe-en une existante depuis **Nexus**, la fonctionnalité in-game de Missions Creator. Après l'avoir importée, essaie de la modifier pour voir comment c'est fait.
