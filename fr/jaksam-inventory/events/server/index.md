Le système d'inventaire déclenche plusieurs events quand des items sont ajoutés, retirés ou transférés. Tu peux écouter ces events pour implémenter ta propre logique.

| Event | Description |
| --- | --- |
| [Item d'inventaire ajouté](/fr/jaksam-inventory/events/server/on-inventory-item-added) | Se déclenche quand un item est ajouté avec succès à un inventaire |
| [Item d'inventaire retiré](/fr/jaksam-inventory/events/server/on-inventory-item-removed) | Se déclenche quand un item est retiré avec succès d'un inventaire |
| [Item d'inventaire transféré](/fr/jaksam-inventory/events/server/on-inventory-item-transferred) | Se déclenche quand un item est transféré avec succès entre inventaires |
