---
title: "Comment mettre à jour"
description: "Étapes pour mettre à jour ton script tout en conservant ta configuration"
icon: "cloud-download"
tag: "Update"
---

<Steps>
  <Step title="Télécharge la dernière version">
    Va sur [FiveM Portal](https://portal.cfx.re/login) pour mettre à jour le script (télécharge-le simplement à nouveau).
  </Step>
  <Step title="Conserve ta configuration">
    Si ton script actuel a un fichier `current_config.json`, conserve-le pour sauvegarder tes modifications et l'utiliser dans la nouvelle version mise à jour.
  </Step>
  <Step title="Vérifie les changements de base de données">
    Consulte les canaux de mises à jour pour être informé de tout changement de base de données.
  </Step>
</Steps>

<Danger>
  Ne conserve **PAS** le fichier `default_config.json`, utilise toujours celui inclus dans le dernier téléchargement.
</Danger>

<Info>
  Si la version vers laquelle tu mets à jour n'a pas de `current_config.json`, tu devras reconfigurer les fichiers de configuration après la mise à jour.
</Info>

<Info>
  La version que tu télécharges depuis FiveM Portal sera **toujours** la dernière version disponible.
</Info>
