Les Drug Factories sont des intérieurs achetables où les joueurs peuvent produire des drogues via un processus de production en plusieurs étapes.

## Fonctionnalités

- **Achat** : les joueurs peuvent acheter une factory via le menu ingame. Chaque factory a un prix configuré et une limite de possession par joueur optionnelle
- **Intérieur** : chaque factory utilise une IPL (par exemple un labo de meth, un labo de coke)
- **Stations de production** : les factories ont des stations où les joueurs effectuent les étapes de production (mélange, pressage, versement). Chaque étape consomme des items en entrée et produit des items en sortie après une durée configurée
- **Employés PNJ** : les employés des stations peuvent être engagés comme améliorations, augmentant la vitesse de production via des multiplicateurs configurables. Chaque station prend en charge plusieurs niveaux d'amélioration avec des coûts individuels
- **Stash** : chaque factory dispose d'un stash privé pour stocker les ingrédients et les produits finis
- **Whitelist** : les propriétaires de factory peuvent whitelister d'autres joueurs pour leur donner accès
- **Visiteurs / Sonnette** : les joueurs non whitelistés peuvent sonner à l'entrée de la factory, et le propriétaire peut accepter ou refuser l'entrée
- **Vente** : les propriétaires peuvent revendre leur factory

## Configuration

Tous les paramètres de factory (prix, stations, étapes de production, améliorations, limites de stash) sont gérés via le menu ingame `/drugscreator`.
