---
title: "Cómo actualizar"
description: "Pasos para actualizar tu script conservando tu configuración"
icon: "cloud-download"
tag: "Update"
---

<Steps>
  <Step title="Descarga la última versión">
    Ve a [FiveM Portal](https://portal.cfx.re/login) para actualizar el script (simplemente descárgalo de nuevo).
  </Step>
  <Step title="Conserva tu configuración">
    Si tu script actual tiene un archivo `current_config.json`, consérvalo para guardar tus cambios y usarlo en la nueva versión actualizada.
  </Step>
  <Step title="Revisa si hay cambios en la base de datos">
    Revisa los canales de actualizaciones para estar al tanto de cualquier cambio en la base de datos.
  </Step>
</Steps>

<Danger>
  **NO** conserves el archivo `default_config.json`, usa siempre el que viene incluido en la última descarga.
</Danger>

<Info>
  Si la versión a la que estás actualizando no tiene `current_config.json`, tendrás que configurar de nuevo los archivos de configuración después de la actualización.
</Info>

<Info>
  La versión que descargas desde FiveM Portal **siempre** será la última versión disponible.
</Info>
