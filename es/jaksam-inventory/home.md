# Jaksam Inventory

Bienvenido a la documentación de **Jaksam Inventory**.

Jaksam Inventory es un sistema de inventario potente y flexible diseñado para funcionar con varios de los frameworks y sistemas de inventario más populares de FiveM.

Usa las opciones de abajo para encontrar rápidamente la documentación que necesitas.
