El sistema de inventario activa varios events cuando se agregan, eliminan o transfieren ítems. Puedes escuchar estos events para implementar lógica personalizada.

| Event | Descripción |
| --- | --- |
| [Inventory item added](/es/jaksam-inventory/events/server/on-inventory-item-added) | Se activa cuando un ítem se agrega correctamente a un inventario |
| [Inventory item removed](/es/jaksam-inventory/events/server/on-inventory-item-removed) | Se activa cuando un ítem se elimina correctamente de un inventario |
| [Inventory item transferred](/es/jaksam-inventory/events/server/on-inventory-item-transferred) | Se activa cuando un ítem se transfiere correctamente entre inventarios |
