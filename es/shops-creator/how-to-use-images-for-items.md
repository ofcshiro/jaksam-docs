## Método global

El script te permite usar las imágenes que quieras para los items, vinculadas a su nombre — así que si un item se llama `bread`, la imagen debe llamarse `bread.png`.

Puedes colocar las imágenes que quieras en la carpeta `shops_creator/html/images/`.

## Quiero obtener los archivos de imagen de un inventario

Para personalizar la ruta por defecto donde el script busca las imágenes, abre el archivo `shops_creator/integrations/cl_integrations.lua` y edita la variable `IMAGES_PATH` con lo que quieras.
