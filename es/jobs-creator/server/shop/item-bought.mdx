Se dispara cuando un jugador compra un objeto/arma en un marcador de tienda.

<CodeGroup>

```lua Event
RegisterNetEvent("jobs_creator:shop:boughtItem", function(playerId, markerId, itemName, itemQuantity, totalPrice)
end)
```

```lua Example
RegisterNetEvent("jobs_creator:shop:boughtItem", function(playerId, markerId, itemName, itemQuantity, totalPrice)
    print("Player ID: " .. playerId .. " bought x" .. itemQuantity .. " " .. itemName .. " from shop " .. markerId)
end)
```

</CodeGroup>

### Parámetros

| Nombre | Tipo de dato | Descripción |
| --- | --- | --- |
| `playerId` | integer | ID de servidor del jugador |
| `markerId` | integer | ID del marcador |
| `itemName` | string | Nombre del objeto o arma |
| `itemQuantity` | integer | Cantidad comprada |
| `totalPrice` | integer | Precio total pagado |
