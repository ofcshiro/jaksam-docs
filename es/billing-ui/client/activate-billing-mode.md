---
title: "Activate billing mode"
description: "Deja que el jugador haga clic en un jugador objetivo para abrir el menú de Billing UI."
icon: "hand-pointer"
---

Trigger para activar el modo de facturación, de modo que el jugador tendrá que hacer clic en el jugador objetivo y el menú de Billing UI se abrirá entonces.

```lua Event
TriggerEvent("billing_ui:activateBillingMode")
```
